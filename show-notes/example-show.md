# Example Show: notes for the Spotter

An example of what a show's notes can hold. Only this show's notes are sent to the
Spotter when it reads this show. Write what's different about this show from the
general rules in spotter-rules.md. Never put feed URLs or anything private here: this
file is committed to git.

- **Breaks start** with "We'll be right back after this."
- **Breaks end** with "Okay, we're back." That line is the show. Keep it.
- **The hosts' own reads:** what to keep, what to cut, and how to tell them apart.
- **Repeat sponsors:** names you'll see in most episodes.
- **Keep:** anything this show does that a careless spotter might cut.
